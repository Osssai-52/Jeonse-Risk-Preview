# 전세사기 미리보기

서울시 행정동 단위 전세거래 취약도 지수(S-JVWI)로 **아직 피해가 드러나지 않은 전세사기 위험지역**을 사전 탐지하는 모델입니다.

> 2026 빅데이터 캠퍼스 활용 아이디어톤 · 팀 AI2P

---

## 왜 만들었나

전세사기 피해 통계는 후행지표입니다. 대부분의 전세가 2년 계약이라 계약 시점에 이미 깡통전세여도 만기가 와야 미반환이 발생하고, HUG 보증사고 집계와 특별법상 피해 인정까지 다시 시간이 걸립니다. 실제로 2022년 말 사태가 불거졌지만 보증사고 건수는 2022년 1,109건 → 2024년 2,455건으로 1~2년 뒤에야 폭증했습니다.

즉 **피해 지도를 그리면 항상 늦습니다.** 그래서 피해 통계 대신 계약 시점에 관측 가능한 구조적 변수만으로 위험을 점수화하고, 과거 피해 데이터는 예측 대상이 아니라 검증용으로만 사용했습니다.

---

## 접근

- **단위**: 자치구 25개가 아닌 **행정동 424개** (분석 완전 케이스 416개)
- **입력**: 실거래가 · 건축물대장 · 공시지가 · 거주인구 · 행정동 경계 (2024.06~2026.05)
- **검증**: 자치구별 전세사기 피해건수 (2023~25, 공공데이터포털)

입력 변수는 모두 최신 시점으로 통일하고, 과거 피해와의 상관으로 모델 방향이 맞는지 확인하는 구조입니다.

## 파이프라인

```
데이터 수집 → 행정동 공간DB 구축 → 변수 생성(16개) → 변수 선택 → 정규화
  → S-JVWI 지수 산출 → K-Means 군집 → 피해 데이터 검증 → 다음 위험지역 도출
```

주요 처리
- 실거래가·건축물대장(법정동)과 인구(행정동)를 KIKmix 매핑표로 통일 — 매칭률 98.8%
- 면적·거리는 EPSG:5179, 시각화는 WGS84로 분리
- 전세가율은 순수 전세 거래(월세=0)만 사용, 비현실값(>200%) 제거
- 단독·다가구는 면적 기준 불일치로 가격 변수에서 제외하고 분포·밀집 변수로만 반영
- Min-Max 정규화 + 공시지가 괴리 상하 1% winsorize

## 방법

| 목적 | 방법 |
|---|---|
| 변수 선택 | Spearman 상관 + RandomForest 중요도 + SHAP |
| 지수 산출 | Min-Max 정규화 후 가중합 (0~100) |
| 유형 분류 | K-Means (엘보우·실루엣으로 k=7) |
| 밀집도 | KDE 커널밀도추정 |

변수를 연구자가 고르면 원하는 결론이 나오므로, 주택유형 구분 없이 공통 변수를 넓게 만든 뒤 데이터가 선택하게 했습니다.

## 결과

**1. 다가구 밀집이 핵심 변수**

Spearman 상관·RandomForest 중요도 양쪽에서 다가구 밀집(r=0.63)이 사실상 1위였습니다. 인구밀도가 r=0.74로 더 높지만 위험 자체보다 노출량 성격이 강해 가중치는 낮게 두었습니다. 최종 가중치는 다가구 밀집 20 / 신축 밀집도 18 / 전세가율 18 순으로, 상위 3개가 전체의 56%를 차지합니다.

**2. 지수가 실제 피해를 설명**

| 검증 항목 | 값 |
|---|---|
| 자치구 취약도 ↔ 누적 피해 | r = 0.688 (p = 0.0001) |
| 인구당 피해 기준 | r = 0.768 |
| 취약도 상위 25% 동의 고피해 자치구 적중률 | 72% |

K-Means 군집 역시 평균 취약도가 높은 순서대로 평균 피해가 높았습니다(복합위험형 46.5 → 882건, 저위험형 18.0 → 151건). 사후 정보 없이 구조적 변수만 썼는데도 '빌라왕' 사태의 진앙지인 강서구 화곡동이 상위 동에 포착됐습니다.

**3. 다음 위험지역 29개 동**

`취약도 상위 25%` ∩ `자치구 피해 하위 50%` — 위험 신호는 쌓였지만 아직 피해 통계에는 잡히지 않은 지역입니다.

- 광진구 8동 (군자·화양·중곡), 강북구 6동 (수유·우이·인수), 종로·도봉·마포 등
- 광진구는 관악구와 취약도가 37로 동일하지만 누적 피해는 134건 대 2,292건으로 17배 차이
- 위험 성격은 두 갈래로 갈립니다 — **주거 다가구형**(광진·강북, 시세 불투명한 다가구 밀집)과 **도심 오피스텔형**(종로·중구, 청년 1인가구 수요 집중)

## 한계

- **동 단위 피해 데이터 부재** — 검증을 자치구 단위로 우회했습니다.
- **시세 조작형 사기 미포착** — 동작구는 피해 974건인데 전세가율 53.6%, 고전세가율 4.7%로 오히려 안전하게 나옵니다. 신축빌라 사기는 매매가를 처음부터 부풀리기 때문에 부풀린 가격 기준 전세가율이 정상처럼 보입니다. '신축빌라 시세 신뢰도', '거래 실적 희소성' 변수 추가가 필요합니다.
- **단독·다가구 전세가율 산출 불가** — 건물 1채 매매 vs 세대별 전세로 면적 기준이 다릅니다.
- **가중치는 초기값** — 피해 상관·문헌 기반이며 SHAP 기반 보정이 남아 있습니다.

## 실행

```bash
pip install -r requirements.txt

python src/01_preprocess.py   # 행정동 매핑 · 좌표계 · 마스터 테이블
python src/02_features.py     # 변수 생성
python src/03_index.py        # 정규화 · S-JVWI 산출
python src/04_cluster.py      # K-Means 군집
python src/05_validate.py     # 상관 · RF · SHAP 검증
python src/06_visualize.py    # 지도 · 차트
```

```

outputs/       지도, 차트, 결과 테이블
```
