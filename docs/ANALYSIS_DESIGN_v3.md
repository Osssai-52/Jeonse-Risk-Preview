# 분석 설계서 v3 — 유형 무관 공통변수 + 데이터 기반 변수선택

## 핵심 원칙
주택유형으로 데이터를 가르지 않는다. 행정동을 단위로, 모든 동에 똑같이
적용되는 공통 변수를 만든다. 그중 전세사기와 유의미하게 연결되는 변수를
데이터(피해 CSV 상관 + 모델 중요도)가 선택하게 한다.

"빌라 한정"도 "유형별 별도 모델"도 아니다.
→ 전체를 같은 자로 재고, 결과로 위험 특징(유형 포함)이 도출된다.

## 단독·다가구 처리 (중요)
- 가격(전세가율): 다가구는 건물1개 매매 vs 세대별 전세, 면적기준 달라 산출 불가 → 제외
- 분포·구성·밀집: 표제부 건물 수로 변수화 → 포함
- 즉 다가구는 "가격"은 못 쓰지만 "이 동에 다가구가 얼마나 많은가"로 변수에 들어감
- 다가구 실거래가 다운로드 불필요. 표제부(보유)로 충분.

## 분석 단위
행정동(424개). 유형으로 안 가름.

## 변수 후보 (전부 동 단위, 유형 무관) — 넓게 만들고 데이터가 선택
### 가격위험
- 전세가율: 동 전체 전세거래(아파트+빌라+오피스텔) ÷ 전체 매매
- 고전세가율 비율: 전세가율 80%↑ 거래 비중
- 공시지가 대비 전세가 괴리: 전세보증금 / 공시지가

### 주택유형 구성 (표제부 건물 수 기준, 다가구 포함)
- 다가구 비율, 빌라(연립·다세대) 비율, 아파트 비율, 오피스텔 비율
  (각 유형 건물 수 / 동 전체 주거건물 수)

### 건물위험
- 신축 밀집도: 동 면적당 신축(2021↑) 주거건물 수
- 건물 노후도: 평균 준공경과연수 또는 노후건물 비율
- 건물당 평균 세대수, 소형주택 비율

### 수요·인구
- 청년인구 비율 (팀원)
- 인구밀도

## 변수 선택 방법 (데이터가 고르게)
1. 위 후보를 모두 동 단위로 만든다
2. 각 변수 ↔ 구 단위 피해 CSV 상관분석 → 유의미한 변수 1차 선별
3. 모델(RandomForest) + SHAP으로 변수 중요도 산출 → "전세사기에 유의미한 변수" 확정
4. 중요 변수로 취약도 지수 재구성 (가중치도 중요도 기반)

## 분석 흐름
```
공통 변수 후보 (유형 무관, 다가구 분포 포함)
   ↓ 정규화 + KDE
변수 ↔ 피해 상관 / 모델 중요도 → 유의미 변수 선택
   ↓
취약도 지수 (선택된 변수·중요도 기반 가중치)
   ↓
K-Means 군집 → 위험 유형 프로파일 (어떤 특징 조합이 위험한가)
   ↓
검증: 위험 동 → 구 집계 → 피해 CSV 상관
   ↓
결론: 모델이 도출한 "전세사기 유의미 변수 + 위험 유형"
      (예: 다가구·빌라 밀집 + 고전세가율 + 신축집중)
```

## 추가 다운로드
- 아파트 실거래가 (매매/전세)
- 오피스텔 실거래가 (매매/전세)
- 그 외는 보유 데이터로 충분

## 재사용 (안 버림)
- 빌라 전세가율 로직 → 아파트·오피스텔에 적용
- 표제부 → 주택유형 구성·신축·노후 (다가구 포함)
- KIKmix, 경계, 청년·공시지가, 피해 CSV → 그대로
