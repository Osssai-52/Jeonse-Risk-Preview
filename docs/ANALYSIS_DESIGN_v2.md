# 분석 설계서 v2 — 전체 주택 기준 (범위 확장)

## 변경 배경

v1은 연립·다세대(빌라)만 분석 → "빌라가 위험하다"는 동어반복 위험.
v2는 **전체 주택을 분석 → 모델이 위험 유형(빌라·오피스텔 등)을 스스로 도출**.
"시작부터 빌라 한정"이 아니라 "전체 보고 결과로 빌라·오피스텔 지목"이 목표.

## 주택유형별 데이터 가용성 (중요)

| 유형 | 전세가율 계산 | 분석 포함 | 비고 |
|------|--------------|-----------|------|
| 아파트 | 가능 (호별 매매-전세 대응) | 포함 | 시세 투명, 위험 낮을 것으로 예상 |
| 연립·다세대(빌라) | 가능 | 포함 | 이미 확보 |
| 오피스텔 | 가능 | 포함 | 피해 21%, 추가 다운로드 |
| 단독·다가구 | **불가** | 전세가율 제외 | 지번·면적 개인정보 제한, 건물1개 매매 vs 세대별 전세로 비율 산출 불가 |

→ 전세가율 기반 분석은 **아파트+빌라+오피스텔 3종**.
   단독·다가구는 정량변수에서 빠지되, 발표에서 "데이터 구조상 제외" 명시.

## 핵심 변경점

### 1. 데이터 (추가 다운로드)
- 아파트 매매/전세, 오피스텔 매매/전세 (00 스크립트에 property_type 추가)
- 모든 거래에 **주택유형(housing_type) 컬럼 유지** — 절대 필터로 버리지 말 것

### 2. 변수 (주택유형 살린 채 계산)
| 변수 | v1 | v2 |
|------|----|----|
| 전세가율 | 빌라만 | 전체 3종, 유형 컬럼 유지 |
| 고전세가율비율 | 빌라 | 전체 |
| 주택유형 구성 | 없음 | **신규: 동별 빌라/아파트/오피스텔 비율** |
| 신축 밀집도 | 신축빌라만 | "신축 공동주택 밀집도" 일반화 + 유형별 |
| 공시지가괴리·청년 | 동일 | 동일 |

### 3. 분석 흐름 (유형이 결과로 드러나게)
```
전체 주택 변수
   ↓ MinMax 정규화 + KDE
취약도 지수 (S-JVWI) — 전체 기준
   ↓
K-Means 군집 ← 여기가 핵심
   "빌라·오피스텔 밀집 + 고전세가율 + 신축집중" 군집이 위험 유형으로 도출
   ↓
검증: 위험 군집이 실제 피해 구(관악·강서·동작·금천)와 겹치나
   ↓
결론: 모델이 지목한 위험 유형 = 특정 주택유형·특징 조합
      → 빌라·오피스텔이 데이터로 확인됨 (한정 아닌 도출)
```

### 4. 최종 산출물 — "유형·특징별 위험 모델"
군집별로 위험 프로파일 제시:
- 군집 A: 빌라 밀집 + 고전세가율 → 고위험
- 군집 B: 오피스텔 밀집 + 신축집중 → 고위험
- 군집 C: 아파트 위주 → 저위험
- 각 군집의 주택유형 구성·전세가율·신축비율을 표로 → "어떤 특징 조합이 위험한가"

## 재사용 가능한 것 (안 버려도 됨)
- 빌라 전세가율·신축빌라 밀집도 계산 로직 → 아파트·오피스텔에 그대로 적용
- KIKmix 매핑, 행정동 경계, 공시지가·청년 변수(팀원) → 전부 그대로
- 검증 구조(구 단위 피해 CSV) → 동일

## 즉 되돌아가는 작업
1. 아파트·오피스텔 실거래가 추가 다운로드 (00)
2. 전세가율·고전세가율 재계산 (전체 3종, 유형 컬럼 유지) (03)
3. 주택유형 구성 변수 신규 (02)
4. 신축 밀집도 일반화 (02)
이후 04~09는 v1 설계 거의 그대로.
